A Data Analytics and NLP project that analyzes customer reviews and classifies them as Positive, Negative, or Neutral using sentiment analysis techniques.
# Customer Feedback Sentiment Analysis

## Project Overview

This project performs sentiment analysis on customer reviews using Natural Language Processing (NLP).

The system classifies customer feedback into:

- Positive
- Negative
- Neutral

The goal is to help businesses understand customer opinions and improve products and services.

---

## Technologies Used

- Python
- Pandas
- TextBlob
- Matplotlib

---

## Features

- Customer Review Analysis
- Sentiment Classification
- Data Visualization
- NLP-Based Insights

---

## Dataset

The dataset contains customer reviews collected from users.

Example:

| Review |
|----------|
| This product is amazing |
| Worst purchase ever |
| Average experience |
